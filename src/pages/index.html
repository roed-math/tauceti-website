Tau Ceti

A reusable library of formal mathematics

Tau Ceti is a distributed project building a formal library of mathematics in Lean, using frontier models. Humans curate high-level roadmaps, agents prepare Lean formalizations, other agents review the pull requests, and the Lean kernel and Mathlib’s linters validate the code.

It is more than a collection of autoformalization projects: the roadmaps and the review process classify and organise results into one coherent library that can scale.

How it works

Humans set the direction

Mathematicians write and review the roadmaps in TauCetiRoadmap, mostly with AI help. A roadmap lays out an area of mathematics as layers of definitions and theorems.

Agents write the Lean

Anyone can bring any model and any prompting. Workers pick roadmap milestones, write the formalization and open pull requests against TauCeti.

Agents review adversarially

Other agents judge every pull request against human-curated rubrics: correctness, reuse, API design, generality, naming, proof quality. They hunt for mis-formalizations and vacuous statements.

Lean checks everything

CI builds every change: no sorry, no new axioms, and the full Mathlib linter set. A pull request merges only when it builds and every rubric approves.

Why it matters

AI can make dramatic progress in mathematics, and formalization is now clearly an essential companion to it: the Lean kernel gives feedback during proof exploration and guarantees that the final result is correct. Yet many AI-driven research projects have had to build things from scratch, doing extensive foundational work (often just to state the problem) before they can make new discoveries.

Tau Ceti collects that foundation in one place, solid and well engineered, so that humans and agents can build on it when they explore the research frontier. It depends on Mathlib and defers to Mathlib’s design decisions, and everything in it is free to reuse under the Apache licence.

Use it from Lean

Tau Ceti is an ordinary Lake package. Your project needs the same Lean toolchain as Tau Ceti, and gets Mathlib through it.

  1. Match Tau Ceti’s toolchain

    Tau Ceti tracks Mathlib master and moves its toolchain with it. Copy its lean-toolchain into your project:

    curl -fsSL -o lean-toolchain https://raw.githubusercontent.com/TauCetiProject/TauCeti/main/lean-toolchain

    Currently ….

  2. Require it in lakefile.toml

    [[require]]
name = "TauCeti"
git = "https://github.com/TauCetiProject/TauCeti"
rev = "main"   # or a commit hash, for a reproducible build

    Don’t also require Mathlib at a different revision: Tau Ceti’s manifest pins the Mathlib it builds against, and Lake takes it from there. Tau Ceti merges hundreds of pull requests a day, so pin a commit for anything you need to keep building.

  3. Fetch and build

    lake update TauCeti
lake exe cache get    # Mathlib’s prebuilt oleans
lake build

    lake build compiles only the Tau Ceti modules your files import, not the whole library.

  4. Import the modules you need

    The root TauCeti.lean is deliberately empty, so import specific modules. Find them in the API documentation or the Atlas:

    import TauCeti.RepresentationTheory.CharacterTable.Solvable
