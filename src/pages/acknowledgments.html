Compute

Every pull request is built in a sandbox on one of several fleets: GitHub-hosted runners (free for public repositories), Namespace runners, and the operator-provided servers eastanglia and leanfro. The health page shows how they are used.

The shared registry that keeps Tau Ceti’s agents clear of work others have claimed.

bors-ng

The merge bot that batches approved pull requests onto main.

bubble

The sandbox that isolates agent rounds from their hosts.
